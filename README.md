# Donovan Faglain – Portfolio

CV en ligne : administrateur systèmes et réseaux en alternance (SPEMA Cap Group), Mastère MICSI au CESI de Châteauroux.

Site statique (HTML/CSS) publié avec GitHub Pages.

## Fichiers

- `index.html` : la page du site (textes, mise en forme et petit script du panneau de brassage)
- `cv-donovan-faglain.pdf` : le CV téléchargeable depuis le site

## Modifier le site

Ouvrir `index.html` (directement sur GitHub avec le crayon, ou dans VS Code), changer le texte voulu, puis enregistrer / committer. GitHub Pages met le site à jour en une ou deux minutes.
