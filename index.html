    Migration des machines virtuelles vers Windows Server 2022 Datacenter

    SPEMA Cap Group

    Terminé
    • Hyper-V
    • Windows Server 2022
    • Virtualisation

    Contexte
    Les quatre machines virtuelles Hyper-V qui portent les services critiques de l'entreprise (Active Directory, serveur de fichiers, ERP, Azure AD, serveur de licences) tournaient sur un serveur physique sous Windows Server 2019 qu'il fallait remplacer.

    Application de gestion des baies de brassage

    Projet personnel, utilisé en entreprise

    En service
    • Electron
    • JavaScript
    • Application Windows
    • Documentation réseau
    • Développement assisté par IA
    Le besoin
    Avoir une vue d'ensemble, et détaillée, du câblage physique du réseau : quelle prise arrive sur quel port de quel panneau.
    Ce que j'ai fait
    J'ai conçu, avec l'aide de Claude (IA), une application de bureau Windows qui représente les baies, les panneaux de brassage, les switchs et les équipements (serveurs, NAS, routeurs), avec les liaisons entre ports, y compris entre switchs. Les données sont enregistrées dans un fichier local et l'application se met à jour d'elle-même.
    Résultat
    Utilisée sur le terrain pour documenter le câblage. Plusieurs versions successives, corrigées et enrichies à partir de cet usage.
